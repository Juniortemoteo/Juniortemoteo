## Projetos em destaque

### [Quick Meal](https://github.com/Juniortemoteo/QuickMeal)

Aplicativo mobile para organizar alimentos da geladeira, acompanhar itens próximos do vencimento e descobrir receitas que aproveitam ingredientes disponíveis. O projeto trabalha o problema do desperdício doméstico com inventário local compartilhado entre telas, persistência no dispositivo e leitura de códigos de barras.

**Tecnologias:** React Native, Expo, TypeScript, Expo Router e AsyncStorage.
